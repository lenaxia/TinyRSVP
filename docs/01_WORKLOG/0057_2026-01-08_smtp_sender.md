## Technical Details

### SMTP Connection Flow

```
1. Dial TCP connection with timeout
2. Create SMTP client
3. Start TLS if configured
4. Authenticate if credentials provided
5. Set sender (MAIL FROM)
6. Set recipient (RCPT TO)
7. Send message data
8. Close connection
```

### MIME Message Structure

**Plain Text:**
```
From: Sender <sender@example.com>
To: recipient@example.com
Subject: Test
Content-Type: text/plain; charset=utf-8

Body text
```

**HTML + Text:**
```
Content-Type: multipart/alternative; boundary=xyz

--xyz
Content-Type: text/plain; charset=utf-8

Plain text version

--xyz
Content-Type: text/html; charset=utf-8

<html>HTML version</html>

--xyz--
```

**With Attachments:**
```
Content-Type: multipart/mixed; boundary=xyz

--xyz
[Body parts]

--xyz
Content-Type: text/calendar
Content-Disposition: attachment; filename="event.ics"
Content-Transfer-Encoding: base64

[Base64 encoded data]

--xyz--
```

### Error Classification

**Permanent Errors (Do Not Retry):**
- 550: Mailbox unavailable (user doesn't exist)
- 551: User not local
- 552: Exceeded storage allocation
- 553: Mailbox name not allowed
- 554: Transaction failed

**Transient Errors (Retry):**
- 421: Service not available
- 450: Mailbox unavailable (temporarily)
- 451: Local error in processing
- 452: Insufficient system storage
