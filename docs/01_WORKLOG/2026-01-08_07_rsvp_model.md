## Key Implementation Details

### RSVP Stats Calculation
The `GetStats()` method efficiently calculates:
- Total invites for event
- Response counts (yes/no/maybe/no response)
- Total guests (sum of 1 + plus_ones for "yes" responses)

Uses a single SQL query with LEFT JOIN and CASE statements for optimal performance.

### Answer Type Validation
Each `RSVPAnswer` must have exactly one answer field populated:
- `AnswerText` for text questions (max 500 chars)
- `AnswerOption` for select questions
- `AnswerBoolean` for boolean questions

Validation enforced at model level before database operations.

### Unique Constraints
- One RSVP per invite (enforced by database UNIQUE constraint)
- One answer per (rsvp_id, question_id) pair

### Cascade Behavior
- Deleting an invite cascades to RSVP
- Deleting an RSVP cascades to answers
- Tested in integration tests
