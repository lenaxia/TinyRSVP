## Design Decisions

### External CSS vs Inline Styles
- Used external CSS file for all styling rules
- Maintained inline style attributes using CSS variables (project pattern)
- This provides consistency with other UI components

### Plus-Ones UI
- Chose increment/decrement buttons over number input
- Better mobile UX
- Clearer affordance
- Still includes hidden input for form submission

### Response Options
- Large, touch-friendly radio button cards
- Visual feedback on selection
- Clear labels
- Accessible keyboard navigation

### Progressive Enhancement
- Form works with standard POST without JavaScript
- JavaScript adds convenience features
- Graceful degradation
