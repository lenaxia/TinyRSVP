## User Story

As a **system developer**, I want **HMAC-SHA256 token hashing** so that **tokens are stored securely in the database and cannot be reversed**.

---

## Acceptance Criteria

- [ ] Tokens hashed using HMAC-SHA256 with secret key
- [ ] Hash output is base64-URL encoded (44 characters)
- [ ] Same token + secret produces same hash (deterministic)
- [ ] Different tokens produce different hashes
- [ ] Different secrets produce different hashes for same token
- [ ] Hash cannot be reversed to obtain original token
- [ ] Hash function is constant-time safe
- [ ] Secret key never logged or exposed

## Technical Details

### Implementation Location
Implemented in `pkg/token/generator.go` as part of the `Generator` interface.

### HMAC-SHA256 Details

```go
func (g *generator) Hash(token string) (string, error) {
    h := hmac.New(sha256.New, g.secret)
    h.Write([]byte(token))
    return base64.URLEncoding.EncodeToString(h.Sum(nil)), nil
}
```

### Hash Properties

- **Input:** 43-character token string
- **Output:** 44-character base64-URL encoded hash
- **Algorithm:** HMAC-SHA256
- **Key:** Secret key from config (minimum 32 bytes)

### Security Properties

1. **Authentication:** Verifies token was generated by system with secret
2. **Integrity:** Detects any modification to token
3. **Non-reversible:** Cannot derive token from hash
4. **Deterministic:** Same input always produces same output
5. **Collision-resistant:** Different inputs produce different outputs

## Testing Strategy

All testing covered in Story 00:

### Hash Consistency Tests
```go
func TestGenerator_Hash_Consistency(t *testing.T) {
    gen := NewGenerator([]byte("secret"))
    token := "test-token"
    
    hash1, _ := gen.Hash(token)
    hash2, _ := gen.Hash(token)
    
    if hash1 != hash2 {
        t.Error("Same token should produce same hash")
    }
}
```

### Hash Uniqueness Tests
```go
func TestGenerator_Hash_Uniqueness(t *testing.T) {
    gen := NewGenerator([]byte("secret"))
    
    hash1, _ := gen.Hash("token1")
    hash2, _ := gen.Hash("token2")
    
    if hash1 == hash2 {
        t.Error("Different tokens should produce different hashes")
    }
}
```

### Secret Key Tests
```go
func TestGenerator_Hash_DifferentSecrets(t *testing.T) {
    gen1 := NewGenerator([]byte("secret1"))
    gen2 := NewGenerator([]byte("secret2"))
    token := "test-token"
    
    hash1, _ := gen1.Hash(token)
    hash2, _ := gen2.Hash(token)
    
    if hash1 == hash2 {
        t.Error("Different secrets should produce different hashes")
    }
}
```

## Security Considerations

1. **HMAC vs Plain Hash**
   - HMAC provides authentication (requires secret key)
   - Plain SHA256 would allow anyone to verify tokens
   - HMAC prevents token forgery

2. **Secret Key Management**
   - Generated on first startup
   - Stored in database config table
   - Never logged or exposed in errors
   - Key rotation invalidates all tokens

3. **Timing Attack Resistance**
   - HMAC implementation is constant-time
   - Hash comparison uses `hmac.Equal()` (constant-time)
   - Prevents timing-based token guessing

4. **Hash Storage**
   - Only hash stored in database, never plain token
   - Token shown to user once during creation
   - Cannot recover token from hash
