## User Story

As a **guest**, I want **a simple, mobile-friendly RSVP form** so that **I can easily respond to an invitation**.

---

## Acceptance Criteria

- [x] Event details display (title, date, location)
- [x] RSVP response options (yes, no, maybe)
- [x] Plus-ones selector (if allowed)
- [x] Preference questions display
- [x] Form validation
- [x] Submit button with loading state
- [x] Mobile-optimized layout
- [x] Touch-friendly controls
- [x] Works without JavaScript (progressive enhancement)

---

## Technical Details

RSVP page should be simple, focused, and fast-loading. Event details at top, form below. Single-column mobile layout.
