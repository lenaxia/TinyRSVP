## User Story

As a **guest**,  
I want to **see the RSVP page with the event manager's custom color applied**,  
So that **the invitation matches the event's branding**.

---

## Acceptance Criteria

- [ ] Custom color overrides theme primary color
- [ ] Color applied via CSS variable
- [ ] Color works in light and dark modes
- [ ] Color contrast meets WCAG AA
- [ ] Fallback to theme default if no custom color

---

## Tasks

- [ ] Update RSVP rendering to apply custom color
- [ ] Add CSS variable override
- [ ] Test color application
- [ ] Validate color contrast
- [ ] Write tests
