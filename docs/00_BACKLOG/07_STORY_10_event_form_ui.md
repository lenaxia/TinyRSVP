## User Story

As an **event manager**, I want **an intuitive event creation/edit form** so that **I can easily create and manage event details**.

---

## Acceptance Criteria

- [x] Multi-step or single-page form
- [x] Event details (title, description, location)
- [x] Date/time picker
- [x] Timezone selector
- [x] RSVP deadline picker
- [x] Preference questions management
- [x] Form validation with error messages
- [x] Save draft functionality
- [x] Responsive layout
- [x] Keyboard accessible
