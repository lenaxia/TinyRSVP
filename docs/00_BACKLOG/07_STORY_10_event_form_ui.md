## User Story

As an **event manager**, I want **an intuitive event creation/edit form** so that **I can easily create and manage event details**.

---

## Acceptance Criteria

- [ ] Multi-step or single-page form
- [ ] Event details (title, description, location)
- [ ] Date/time picker
- [ ] Timezone selector
- [ ] RSVP deadline picker
- [ ] Preference questions management
- [ ] Form validation with error messages
- [ ] Save draft functionality
- [ ] Responsive layout
- [ ] Keyboard accessible
