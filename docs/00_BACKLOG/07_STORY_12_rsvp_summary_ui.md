## User Story

As an **event manager**, I want **to view RSVP summary and analytics** so that **I can track attendance and plan accordingly**.

---

## Acceptance Criteria

- [ ] RSVP count summary (yes, no, maybe, pending)
- [ ] Plus-ones count
- [ ] Response rate percentage
- [ ] Visual charts/graphs
- [ ] Preference question responses summary
- [ ] Export responses
- [ ] Filter by response type
- [ ] Responsive layout
