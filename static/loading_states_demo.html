Accessibility Features

  • ARIA Support: All loading states include aria-busy, aria-live, and role attributes
  • Reduced Motion: Animations respect prefers-reduced-motion preference
  • Keyboard Navigation: Loading states disable interactions appropriately
  • Screen Reader: Loading announcements via aria-live regions

Try enabling "Reduce motion" in your OS accessibility settings to see animations pause.
