Navigation Test Page

This page tests the updated slide-out navigation component.

Expected Behavior

  • Desktop (≥768px): Navigation links visible horizontally in top bar, no hamburger button, no overlay
  • Mobile (<768px):
    • Hamburger button visible in top bar
    • Menu hidden off-screen to the left by default
    • Clicking hamburger slides menu in from left and shows dark overlay
    • Menu covers full height of viewport
    • Clicking overlay, close button (×), or pressing Escape closes menu
    • Body scroll disabled when menu is open

Test Instructions

  1. Resize browser window to <768px width to test mobile view
  2. Click hamburger button - menu should slide in from left with overlay
  3. Click overlay (dark area) - menu should close
  4. Open menu again, click × button - menu should close
  5. Open menu again, press Escape key - menu should close
  6. Resize to ≥768px - menu should appear in top bar, overlay should disappear
